# Antonio Bečić · Portfolio

Personal portfolio of Antonio Bečić, Full-Stack & AI Engineer.

**Live:** https://antonio-becic.vercel.app

## What's inside

- About, experience, selected work (Frankfurt Forecast, Calisto, Sport4You) and skills
- **Ask my CV**: a small retrieval demo that answers questions from CV passages in the browser and shows the source of every answer
- Light and dark themes with a manual switch

It is a single static `index.html` with no build step. Screenshots live in `shots/`, logos in `logos/`.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

```bash
vercel deploy --prod
```
